# 観点ベクトルを用いた観光地推薦システム

本研究では，観光地の口コミおよび説明文から観点ごとの特徴を抽出し，
観点情報に基づくコンテンツベース推薦を行うシステムを構築した．
また，観点の利用方法が異なる複数の推薦手法を比較し，
ユーザ評価への影響を分析する．

## 機能
- 観光地の観点別スコアの算出
- ユーザ嗜好に基づく観光地推薦
- 複数手法（4種類）の比較

## システム概要
1. 口コミ・説明文を入力
2. 観光地ベクトル・観点ベクトルを生成
3. 類似度から観点別スコアを算出
4. 推薦スコアを計算しランキング

## 実行方法

```bash
pip install -r requirements.txt
python app.py
```
なお，実際の実験はStreamlitで実験した．
